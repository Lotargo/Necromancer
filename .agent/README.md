# .agent — Инструменты для AI-агентов

Эта директория содержит вспомогательные инструменты и workflows для AI-агентов (Antigravity, Cursor, Copilot и др.), работающих с данным проектом.

---

## 🔧 Terminal Bridge (Мост к терминалу)

### Проблема

В некоторых IDE-надстройках (Antigravity, Cursor и др.) встроенный инструмент `run_command` **периодически зависает** — команда отправляется, но вывод не возвращается. Проблема непостоянна и связана с Terminal API VS Code.

### Решение

Файловый мост: агент записывает команду в файл → скрипт в терминале пользователя выполняет её → результат записывается в файл → агент читает результат.

### Структура

```
.agent/
├── README.md              ← этот файл
├── tools/
│   └── terminal_bridge.ps1  ← скрипт-мост (запускается пользователем)
├── workflows/
│   └── terminal.md          ← workflow для агента
└── tmp/                     ← временные файлы (в .gitignore)
    ├── cmd_input.txt        ← команда от агента
    └── cmd_output.txt       ← результат выполнения
```

### Запуск (для пользователя)

```powershell
powershell -ExecutionPolicy Bypass -File .\.agent\tools\terminal_bridge.ps1
```

Скрипт будет работать в фоне, подхватывая команды от агента.

### Использование (для AI-агента)

#### Шаг 1: Отправить команду

Записать команду в `.agent/tmp/cmd_input.txt` через `write_to_file` (с `Overwrite: true`):

```
CWD:f:\TEAM\agentic-rag
go build ./...
```

- Строка `CWD:` — опциональна, задаёт рабочую директорию
- Всё остальное — команда для выполнения
- Команды выполняются через `cmd /c`, используйте Windows-синтаксис

#### Шаг 2: Прочитать результат

Через 2-3 секунды прочитать `.agent/tmp/cmd_output.txt` через `view_file`:

```
STATUS:DONE
EXIT_CODE:0
TIME:1.2s
---OUTPUT---
<вывод команды>
```

- Если `STATUS:RUNNING` — подождать и прочитать снова
- Если `STATUS:DONE` — команда завершена, проверить `EXIT_CODE`

#### Шаг 3: Если bridge не запущен

Если файл `cmd_output.txt` содержит `READY` или не существует — попросить пользователя запустить скрипт.

### ⚠️ Важно

- Скрипт должен быть **запущен пользователем** в его терминале
- Временные файлы в `.agent/tmp/` добавлены в `.gitignore`
- Скрипт опрашивает входной файл каждые 300мс
- Перед отправкой новой команды убедитесь, что предыдущая завершена (`STATUS:DONE`)
