Necromancer

A retro‑futuristic chat interface and backend system wrapped in arcane aesthetics.

View Repository

Features

Retro CRT Experience

Immersive terminal with scanlines, chromatic aberration, matrix rain, dripping blood, occult symbols and adaptive audio for a true retro feel.

Robust Backend

FreePascal core daemon with modular architecture managing sockets, a PostgreSQL database, Argon2id security and key management.

Dynamic AI Oraculum

Interact with the AI Oraculum via Latin incantations using tools for web search, knowledge retrieval, code execution, simulations and more.

Load Balancing & Provider Failover

A Lua‑based balancer distributes requests across multiple LLM providers and automatically rotates or quarantines API keys.

User Journeys & Security

Guest and registered login modes, cryptographically hashed credentials, user level progression and complete profile control.

Containerized Deployment

Simple docker‑compose setup to summon the entire stack with customizable .env and provider configuration.

System Architecture

  1. Daemonium: FreePascal backend core managing socket connections, authorization and chat history.
  2. Interpres: PHP and JavaScript front‑end providing the CRT UI, SSE streaming, canvas overlays and failover logic.
  3. Aequilibrium: Lua load balancer handling provider rotation, key rotation and session pinning.
  4. Tabularium: PostgreSQL database storing users, options, chat logs and key registry.
  5. Mechanica: Secure sandbox for compiling and executing Pascal code and running simulations.
